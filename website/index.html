RETH Labs · Hardware y software

RETH Optimicer

Un optimizador todo en uno, minimalista y profesional. Limpia, ajusta y mantiene Windows y Linux sin bloatware ni anuncios.

Instalador Windows Código fuente

Windows 10/11 · Linux · GPL-3.0 · v3.0.0

Potente, sin ruido

Las funciones que importan, agrupadas con criterio. Nada de trucos milagrosos.

Memoria

Libera working set, caché y standby de forma controlada. En Linux, drop caches con privilegio explícito.

Disco

Temporales, papelera, miniaturas, logs y cachés de desarrollo. TRIM cuando corresponde.

Red

DNS con latencia real: Cloudflare, Google, Quad9, AdGuard. Flush y ajustes TCP seguros.

Servicios e inicio

Control de arranque y servicios. En Windows, perfiles; en Linux, systemd y autostart.

Privacidad

Telemetría y recolectores opcionales, desactivados solo con tu confirmación.

Respaldo

Puntos de restauración antes de cambios profundos. Nada se aplica a ciegas.

Windows

Aplicación nativa WPF, instalador de un clic, bandeja del sistema y modo administrador cuando hace falta.

  • Instalador Inno Setup / MSI
  • Ejecutable único self-contained
  • .NET 8, Windows 10 19041 o superior

Linux

Cliente GTK 4 + libadwaita. Acciones privilegiadas por pkexec, con lista blanca. Sin dependencias pip.

  • Script install.sh (usuario o sistema)
  • Arch, Debian/Ubuntu, Fedora
  • Python 3 + GTK 4

Instalación fácil

Windows

Descarga el instalador, acepta UAC y listo.

RETH_Optimicer_Setup_v3.0.0.exe

Linux

git clone https://github.com/dzenwertz/RETH-Optimicer.git
cd RETH-Optimicer/linux
chmod +x install.sh
./install.sh
reth-optimicer
